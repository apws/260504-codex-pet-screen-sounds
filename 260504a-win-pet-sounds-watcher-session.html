Windows Watcher Behavior

The working Win32 app is now a no-console systray app:

  • Launches without args.
  • Defaults to an 80x80 DIP rectangle at the bottom-left of the selected monitor.
  • At the tested monitor setting 1920x1200 @ 96 DPI, this maps to left=0 top=1120 width=80 height=80.
  • Captures pixels via GDI BitBlt and compares BGRA bytes against the previous frame.
  • Plays C:\Windows\Media\ringout.wav on any bitmap difference.
  • Shows a tray icon with a green square in the bottom-left and has a right-click Exit menu.

Known nature of the workaround: it detects pet pixel changes, not agent state. Pet animation timing can produce one short ring, one full ring, or two rings.

macOS Notes

Original plan was a native macOS menu-bar version under codex-pet-watch/macosx/. Later in the session this was implemented as source-prepared Objective-C/AppKit code, but not compiled on Windows.

Implemented design:

  • Separate native Objective-C/AppKit app, not a Win32 port.
  • NSStatusItem menu-bar icon with Exit.
  • CGDisplayCreateImage / CoreGraphics crop of a bottom-left pet rectangle.
  • NSSound playback, with bundled shared ringout.wav when built.
  • Requires Screen Recording permission on macOS Catalina and newer.
